## 已接受决策

### DEC-20260803-001：先用 Git Markdown 知识库，不先上复杂记忆框架

- 状态：accepted
- 范围：global
- 决策人：用户
- 日期：2026-08-03
- 标签：知识库, 记忆系统, 新手方案

### 背景

用户希望把聊天过程中产生的经验结论沉淀到知识库，不希望停留在会话中。但当前还是新手，不适合一开始搭建复杂系统。

### 决策

先做 Git Markdown 知识库和 `AGENTS.md` 规则；后续再做自动检查；最后才考虑记忆框架。

### 理由

Markdown 文档简单、透明、可版本化、容易人工维护，也方便以后接入 CLI、Hook、MCP、全文检索或向量索引。

### 不采用的方案

- 一开始使用 LangGraph、Mem0、Graphiti、向量库等复杂系统。
- 不采用原因：学习成本和维护成本高，容易还没形成知识闭环习惯就先被工具复杂度拖住。

### 影响

后续项目优先把边界、决策、经验、流程和偏好写入 `知识库/` 目录。

### 证据或来源

- 本次会话中用户确认：“先做 Git Markdown 知识库 + AGENTS.md 规则；再做自动检查；最后才上记忆框架。”
